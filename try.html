Try it yourself

You need a Windows PC and the free Rust tools. Four steps.

  1. Install Rust from rustup.rs. This is what builds the game.
  2. Download or copy the project folder.
  3. Double-click launch.bat. The first run takes a few minutes to build. Later runs are quick.
  4. The game opens on a main menu. Press Play, then walk with W A S D, hold Shift to run, press Space to jump, and look with the mouse. Esc opens a pause menu and the game keeps running behind it.

To use the character creator, double-click launch-editor.bat instead. That is the editor. Its World tab lets you fly around the map, place and move things, save, and press Play to walk in it.

To run every check on the code instead, double-click master-test.bat.

How it is put together

Each part lives in its own box and does one job, so one part can change without breaking the others.

The game

The rules and the player's experience. Will tie everything together.

The engine

The window, the camera, the drawing, the keyboard and mouse.

The content files

Items, skills and recipes written as plain text in .goose files. Changing the game should mean editing text, not code.

The tools

Small scripts that make the character and the hat, and check them for mistakes.

The rule behind it: every part must be Separate, Stable, Improvable, Malleable and Scalable. Short version: parts do not reach into each other, they are tested, and they can be swapped out.
