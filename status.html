Where it stands

What you can do today, what is missing, and what comes next.

Works today

You can run all of this on your own computer.

  • Works today: Building looks and textures

    The Models tab builds a thing from boxes, cylinders and ramps that snap together, with colours and patterns. Click, right-click and drag handles work on each part. Saved as a model file next to the map, and the game draws placed things from it.

  • Works: A 3D world

    A window with a flat ground and a grid. Drag the mouse to orbit the camera. Scroll to zoom.

  • Works: A character you walk

    Move with W A S D or the arrow keys. Hold Shift to run press Space to jump and hold Ctrl to crouch and move slowly. The camera follows. The character switches between standing, walking, running, jumping and crouching by itself. Tested in code; not yet seen in the running window.

  • Works: Main menu and pause

    The game opens on a menu with Play and Quit. Esc pauses and shows Resume, Main menu and Quit. The world keeps running while the menu is open. Tested in code; not yet seen in the running window.

  • Works: A character creator (in the editor)

    Pick skin, hair (ten styles), shirt and pants. Choose Male or Female. Pick a face: eyes, brows, mouth, five expressions, and blinking.

  • Works: The Goose hat

    The first wearable item. A toggle in the creator puts it on the head. Hair hides while it is worn.

  • Works: The Goose cape

    A separate creator toggle wears it over the back and chest. White panels stay visible from either side and connect to the back over the shoulders. It moves with the chest.

  • Works: Test mode

    The Test button hides the menus and lets you look around with the mouse. Esc brings the menus back.

  • Works: Maps

    A map is a text file listing where things go. The game reads it and the checker tool tests it. The editor can place, move, delete and save things on a map, and start the game on it. You can undo mistakes, pick many things at once, move, turn and resize them with handles, copy them, browse and edit all the game content, see changes live in the running game, set the time of day and haze, sculpt hills, shadows from the sun, chop trees and craft planks, rename a map, resize the ground and start a new map. Tested in code; not yet seen in the running window.

  • Works: An editor tutorial

    A Tutorial button in the editor's top bar opens eleven steps, from flying around to looking at a model. Each step ticks itself when you do it, and you can tick it by hand. Tested in code; not yet seen in the running window.

  • Works: Webcam mocap workbench

    A local check confirms the Logitech C615 preview and pose detection at 1280 × 720, using device 0. The current framing misses most leg landmarks, so a full-body take needs another camera-positioning pass. Camera video is never saved; the tool is separate from the game.

  • Partly: Gathering and crafting rules

    The code for harvesting and crafting exists and has tests. It is not connected to the game window yet.

Not yet

Being honest about this keeps the project clear.

  • Not yet: Collisions

    The character can walk through anything. There is no physics.

  • Not yet: Bending bodies

    Arms and legs are stiff pieces that rotate. They do not bend smoothly at the joints.

  • Not yet: Playing the game

    No trees to cut, no items to pick up, no crafting in the window. Only the rules exist.

  • Not yet: A full female body

    The Male / Female choice changes the hair list and adds a bust shape. Hips, shoulders and the rest of the body are the same for both.

  • Not yet: Live editing

    After changing the code or the content files, the game must be closed and started again.

  • Not yet: Phones

    Windows PC comes first. Android is planned after. iOS comes later.

  • Not yet: Goose webcam animation clips

    The workbench can save and review pose estimates, but lower-body tracking needs improvement. It cannot yet turn a take into an animation for the Goose character.

Next up

In this order, one at a time. No dates.

  1. A better editor. Paint textures on the ground, and a limit on how steep you can walk.
  2. Collisions. Stop the character walking through things.
  3. Smooth bending. Make arms and legs bend like skin instead of stiff blocks.
  4. Saving and shops. Keep your backpack between sessions, and sell what you make.
  5. Make webcam animation clips. Improve tracking, then map a take onto the Goose character and save it as an animation.
