Words explained

New to this? Here is what the odd words mean.

Prototype
A rough early version, made to test ideas. Not a finished game.
Rust
The programming language the game is written in.
Engine
The part of a game that does the general work: open a window, draw 3D, read the keyboard. It knows nothing about the game's rules.
Map (.gmap file)
A short text file that says how big the ground is, where the player starts, and where things like trees go.
Editor
The separate program used to build the game world. The game is what players run; the editor is what the maker runs.
Mesh
A 3D shape made of many small flat triangles.
Rig and joints
The hidden skeleton inside the character. Moving a joint, like the elbow, moves the parts attached to it.
Animation clip
A short recording of joint movements, such as Idle, Walk or Wave.
Flat shaded
Every flat face of a shape has one even colour. It gives the sharp, faceted look.
Smooth shading
Light and dark blend along a surface instead of changing at every edge. The character keeps hard edges at its corners but blends along each flat strip.
Expression
A named look for the face, such as Happy or Surprised. The eyes, brows and mouth move to match.
.goose file
A text file where the game's items, skills and recipes are written. The checker tool is called goosec.
Crate
Rust's word for one self-contained package of code. This project has about ten.
Test
A small program that checks one thing works. They run automatically so mistakes get caught early.
Rapier
The physics engine the game will use for collisions and gravity. It is the only one planned. Not added yet.
